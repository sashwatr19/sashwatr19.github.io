# Portfolio

Hi! I'm a mathematician working at the intersection of cryptography and machine learning, currently finishing an MSc in Industrial and Applied Mathematics at TU Eindhoven. My interests span verifiable computation, privacy-enhancing cryptography, and the mathematics of machine learning. Some of the things I've worked on are below.

## Machine Learning Projects

[Neural Network Closure Model for Burgers' Equation](https://github.com/sashwatr19/sashwatr19.github.io/tree/main/Neural%20Network%20Closure) : A convolutional neural network that learns a closure correction for a coarse-grid solver of Burgers' equation, reproducing high-resolution reference solutions at reduced cost. Built in PyTorch, following Melchers et al. (2023).

[Multi-Instance Contrastive Learning (MICLe)](https://github.com/sashwatr19/sashwatr19.github.io/tree/main/Multi-Instance%20Contrastive%20Learning%20(MICLe)%20Tutorial) : A from-scratch implementation of the MICLe model (Azizi et al.), a self-supervised method for medical image classification, with a tutorial explaining the mechanism and the code. Built in TensorFlow/Keras.

[Comparative Analysis of Machine Learning Methods](https://github.com/sashwatr19/sashwatr19.github.io/tree/main/Comparative%20Analysis%20of%20Machine%20Learning%20Methods) : A comparison of KNN, Logistic Regression, SVM, and Random Forest on the Forest Cover Type dataset, tuned with grid search and cross-validation, with an accompanying report.
